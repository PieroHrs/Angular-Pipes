Demostración de Pipes en Angular

1. Pipe exponential sin exponente (exponent = 1)

{{ base }} elevado a 1 = {{ base | exponential }}

2. Pipe exponential con exponente 2

{{ base }} elevado a 2 = {{ base | exponential:2 }}

3. Pipe exponential con exponente 3

{{ base }} elevado a 3 = {{ base | exponential:3 }}

4. Pipe exponential con exponente 0

{{ base }} elevado a 0 = {{ base | exponential:0 }}

5. Pipe exponential con exponente negativo

{{ base }} elevado a -1 = {{ base | exponential:-1 }}

6. Pipe con valor literal

3 elevado a 4 = {{ 3 | exponential:4 }}

Demostración del Pipe truncate

1. truncate con valor por defecto (limit = 25)

Original: {{ textoLargo }}

Truncado: {{ textoLargo | truncate }}

2. truncate con límite personalizado (limit = 40)

Truncado a 40: {{ textoLargo | truncate:40 }}

3. truncate respetando palabras completas

Palabras completas: {{ textoLargo | truncate:40:true }}

4. truncate con puntos suspensivos personalizados

Con "→": {{ textoLargo | truncate:40:true:' →' }}

5. Texto que no supera el límite (sin cambios)

{{ textoCorto | truncate }}
